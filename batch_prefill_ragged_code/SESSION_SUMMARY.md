## Key Insights

### 发现1: DN配置处于局部最优
当前68.27分数在以下维度已达到最优：
- KV cap百分比: 60%（向上或向下调整都会退化）
- KV cap阈值: 8192（降低到4096无改进，降低到0失败）
- Q维度选择: Q128/Q64混合调度已最优

### 发现2: 性能瓶颈根本原因
**内存带宽饱和**: 
- KV加载与计算完全串行化
- 25-30%时间浪费在等待内存
- 单缓冲架构无法隐藏延迟

**寄存器压力**:
- Q128使用230个寄存器
- 仅2个常驻warp/PEU (25%占用率)
- 无法有效隐藏内存延迟

### 发现3: 突破70+的必要条件
所有测试证实：**渐进式优化已穷尽**

必须采用以下架构级重写之一：
1. **软件流水线** + 异步内存操作（预期10-15%提升）
2. **层次化PV累积**（预期5-10%提升）
3. 两者结合（预期15-25%提升）
